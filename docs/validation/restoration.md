# 真实能源展示恢复

此前验收仅针对fixture，占位图片不能证明真实能源展示恢复。本次新增独立source模式，从用户原本地文件读取真实能源值，fixture仍用于可重复接口测试。

## 数据与范围

- 汇总表“数据平台汇总信息表4.xlsx”合并单元格展开后生成463个筛选节点；9个资源叶，包括陆上/海上/高空风电、集中式/分布式光伏、光热、水力、电网侧、用户侧。
- ZIP索引登记41个有栅格的产品、109个明确日期的GeoTIFF、99个统计Excel引用。原文件不复制、不整包解压、不提交；索引和.env位于忽略目录。
- 默认产品是实际同时有地图和统计的“陆上风电、5MW、容量因子、25km、2021”。旧演示2.5MW/10km/2021虽有栅格，没有相应统计Excel，不用其他产品数值补齐。
- QGIS路径形式继续用作前端业务标识；source在TS中读取已登记GeoTIFF并返回WMS PNG，不假称本机已部署QGIS。
- 点值来自原GeoTIFF第一波段，支持0–360经度和负经度转换，原NoData/非有限值返回null。图例和地图使用同一有效值范围。
- 底图来自[Natural Earth 110m 国家边界](https://github.com/nvkelso/natural-earth-vector)，可离线生成瓦片；遵循其[public domain使用条件](https://www.naturalearthdata.com/about/terms-of-use/)，页面标注Natural Earth，不冒用天地图审图号。
- 原34个省级、375个地级、2891个县级SHP/DBF按原坐标读取。中国点选返回省市县，并可生成原边界高亮；缺失的电网属性不填造。
- 国家名按原统计对齐，“中国”保留原前端省市县联动判断。Y2021等统计列映射为折线图年份，原表格列名和数值保留。
- 账户、验证码、邮件、天气仍在本地隔离运行，未称为生产账户或邮件恢复。

## 复现

需要Node >=22.19、pnpm10.28.2。

~~~powershell
pnpm install --frozen-lockfile
pnpm data:import "F:\CX_notes\cxDlogver\source\_posts\Project\2024_QH_FGKSH"
pnpm dev
~~~

Windows默认Node为22.12、本机已有兼容Node时，可执行 .\scripts\dev.ps1 自动选择新版Node。已实测该脚本选择Node24.19并启动source后端18080及开发页5173，两者健康检查通过。已有18080后端须先停止。

当前预览http://127.0.0.1:4173，开发http://127.0.0.1:5173。切换后重新登录demo_download / Energy-demo-2026；旧Token会失效。首次进入source清除旧演示结果，选中已登记的真实默认产品。菜单、直接链接和刷新均可恢复图层。
